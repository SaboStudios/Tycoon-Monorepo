# Changelog

Workspace-level changes to `contract/` (CI, scripts, `Cargo.toml`, deploy
tooling) are documented here. Changes to a single crate go in that crate's
own `contract/contracts/<crate>/CHANGELOG.md`, as `RELEASE_CHECKLIST.md`
requires. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Add entries under `## [Unreleased]`. CI enforces this; see CONTRIBUTING.md.
